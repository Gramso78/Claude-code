## Note de recherche concurrentielle (limites)

- `facebook.com` est bloqué par la politique réseau de l'environnement d'exécution utilisé pour produire ce document — impossible d'ouvrir directement la Meta Ads Library. Pour lever ce blocage : ajouter `facebook.com` aux domaines autorisés dans les paramètres de l'environnement cloud (menu environnement → Edit → Network access).
- Même avec l'accès, Meta ne publie pas les données de dépense/impressions pour les publicités commerciales classiques (seulement pour les publicités politiques) — donc "qui dépense le plus" n'est de toute façon pas mesurable via la Ad Library pour ce type de campagne.
- Intel récupérée via recherche web (sources ci-dessous) :
  - CapCar : campagne TV (1000+ passages, TF1), angle narratif centré sur le vendeur particulier.
  - Simplicicar (116 agences) : formation franchisé sur 2 semaines, gestion centralisée des réseaux sociaux du réseau.
  - TransakAuto (211 points de vente) : utilise les "Facebook Custom Audiences" — confirme Meta comme canal actif.
  - Étude 2025 (recrutement de franchisés, US) : Facebook = canal n°1 cité, devant LinkedIn (35%) et Instagram (15%).
  - Analyse 2026 pubs de recrutement : vidéos courtes "brutes" (UGC) > créas corporate léchées ; transparence chiffrée > flou.
  - Règle de hook : ~1,7 seconde pour capter l'attention ; affirmations contrariantes ou questions directes sur le coût performent bien.
- Ces éléments sont intégrés au script ci-dessous : ton UGC/facecam plutôt que corporate, transparence chiffrée immédiate, hook contrariant, témoignage réel en BOFU plutôt qu'une créa publicitaire polie.

## BOFU

### Image / carrousel
- **Visuel** : photo réelle d'une agence E-Cars ou d'un agent, overlay avec les 3 chiffres clés
- **Titre** : "15 000 € d'apport. Pas de stock à financer."
- **Texte principal** : *"Ouvrir une agence automobile ne demande pas forcément 300 000 €. Chez E-Cars, votre investissement finance la formation, les outils et l'accompagnement — pas un stock de voitures invendues. Découvrez si votre profil et votre secteur sont compatibles avec le modèle, en 20 minutes, sans engagement."*
- **Description** : "Réseau en pleine expansion — zones encore disponibles."
- **CTA bouton** : "Je réserve mon échange" (→ formulaire de qualification à 6 questions, cf. document principal)
